## 음악 정보 채우기 v0.1.6

### 바뀐 것

- **아티스트 식별 정보를 함께 기록합니다.** 같은 가수가 `岡田 有希子`, `岡田有希子`, `Yukiko Okada`처럼 여러 표기로 저장되어도 나중에 같은 사람으로 묶을 수 있게, 후보를 적용해 저장할 때 이름 글자와 함께 식별자를 태그에 적습니다.
  - MusicBrainz 아티스트·앨범 아티스트·앨범·녹음 ID, 정렬용 이름(예: `Okada, Yukiko`), iTunes 아티스트 ID
  - 태그 이름은 MusicBrainz Picard와 같아 beets·foobar2000 등 다른 도구에서도 읽힙니다. mp3의 녹음 ID는 `UFID:http://musicbrainz.org`에 적습니다.
  - 가수가 여러 명이면 ID도 여러 개 적고, 자동 선택된 파일에도 적습니다. 되돌리기는 식별자까지 원래대로 돌립니다.
  - 위쪽 칸 아래의 "식별자" 줄에서 그 파일에 무엇이 있는지 볼 수 있습니다. 태그 이름 표는 README에 있습니다.
  - `settings.json`의 `artist_name_preference`를 `"latin"`으로 바꾸면, MusicBrainz가 로마자 이름을 명확히 줄 때에 한해 표시용 가수명에 그 이름을 씁니다(기본 `"original"`).
- **앱 아이콘이 생겼습니다.** exe 파일과 창 제목줄·작업 표시줄에 파란 바탕의 음표와 꼬리표 아이콘이 뜹니다.
- README에 표지 일괄 등록 사용법을 넣었습니다.

**알아 두실 점**: 이전 버전으로 저장한 파일에는 식별자가 없습니다. 다시 넣고 후보를 적용(또는 자동 선택)한 뒤 저장하면 붙습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Tag Filler v0.1.6** — Saving now also writes identifiers next to the display names: MusicBrainz artist, album-artist, album and recording IDs, sort names, and the iTunes artist ID, using the same tag names as MusicBrainz Picard (the recording ID goes to `UFID:http://musicbrainz.org` in mp3). That lets a library organiser group one artist across spellings. Undo restores them too; `artist_name_preference` in settings.json can prefer a Latin-script artist name when MusicBrainz clearly provides one. The app also has an icon now.

## 음악 정보 채우기 v0.2.9

체크 상자 모양과 상자 하나의 이름을 고친 버전입니다. 태그·표지·가사·되돌리기·새 버전 확인·의견 보내기는 v0.2.8과 같습니다.

### 바뀐 것

- **체크 상자를 켜면 X 대신 ✓가 보입니다.** 켠 상자는 파란 바탕에 흰 ✓, 끈 상자는 흰 바탕에 회색 테두리입니다. 창 안의 체크 상자 다섯 가지(새 버전 확인, 표지 없는 파일만 검색, 저장 시 파일명도 바꾸기, 저장 후 알림 창 표시, 가사도 채우기)가 모두 이렇게 바뀌었고, 화면 배율 100·125·150%에서 상자 크기와 자리는 전과 같습니다.
- **「표지 없는 파일만 넣기」를 「표지 없는 파일만 검색」으로 바꿨습니다.** 하는 일은 같습니다. 켜 두고 파일이나 폴더를 넣으면 표지가 이미 든 곡은 목록에 올라오지 않고 검색도 하지 않습니다. v0.2.8에서 켜 둔 설정은 그대로 이어지고, 명령줄 `--only-missing-cover`도 그대로입니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Tag Filler v0.2.9** changes how the check boxes look and renames one of them. A ticked box now shows a white ✓ on blue instead of an X; an unticked box is white with a grey border. All five boxes in the window change, and their size and position stay the same at 100, 125 and 150% display scale. **Add only files without a cover** is now called **Search only files without a cover**. It works as before: with it ticked, songs that already have a cover stay out of the list and are not searched. A setting ticked in v0.2.8 carries over, and `--only-missing-cover` on the command line is unchanged. Everything else is the same as v0.2.8. Download `music-tag-filler.exe` and double-click it. The exe is not signed, so if SmartScreen warns, choose "More info → Run anyway".

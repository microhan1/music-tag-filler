## 음악 정보 채우기 v0.2.5

**의견 보내기** 버튼을 키보드로도 누를 수 있게 하고, 마우스를 올리면 짧은 설명이 뜨게 한 버전입니다. 태그·가사·되돌리기·새 버전 확인은 v0.2.4와 같습니다.

### 바뀐 것

- **키보드로 의견 보내기.** Tab으로 「새 버전 확인」 다음에 버튼으로 옮겨 가고, Enter나 Space로 누릅니다. 초점이 오면 버튼 테두리가 파랗게 바뀝니다(크기는 그대로).
- **설명 풍선.** 버튼에 마우스를 올리고 잠깐(0.45초) 있으면 "안 되는 것·불편한 것·바라는 기능을 알려 주세요(브라우저가 열립니다)"가 뜹니다. 마우스를 떼거나 누르면 사라지고, 창이 화면 끝에 있어도 창과 화면 밖으로 잘리지 않습니다. 화면 언어를 바꾸면 설명도 바로 바뀝니다.
- **열리는 페이지 언어.** 한국어 화면이면 한국어 판, 그 밖의 모든 화면 언어는 영어 판 툴 페이지가 열립니다. 「의견 보내기」와 새 버전 알림의 「업데이트」가 같은 규칙을 씁니다.
- 일본어·중국어 README의 의견 칸과 툴 페이지 링크가 영어 판 페이지([chaekgalpi.co.kr/en/tools/musictag#feedback](https://chaekgalpi.co.kr/en/tools/musictag#feedback))로 바뀌었습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

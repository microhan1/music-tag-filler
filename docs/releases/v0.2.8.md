## 음악 정보 채우기 v0.2.8

표지(앨범 사진)가 없는 곡만 골라 넣는 상자를 더한 버전입니다. 태그·가사·되돌리기·새 버전 확인·의견 보내기는 v0.2.7과 같습니다.

### 바뀐 것

- **표지 없는 파일만 넣기.** 이 상자를 켜고 파일이나 폴더를 넣으면 표지가 이미 든 곡은 목록에 올라오지 않습니다. 하위 폴더도 똑같이 거르고, 제목·가수가 다 채워진 곡이라도 표지가 없으면 올라옵니다. 건너뛴 곡 수는 아래 상태 줄 맨 앞에 「표지가 있는 4곡은 건너뜀」처럼 나옵니다.
- 상자는 파일이 없을 때는 표지 단추 아래, 파일 목록이 보이면 「파일 추가 · 폴더 추가 · 비우기」 아래에 있습니다. 처음에는 꺼져 있고, 켜 두면 다음에 열 때도 켜져 있습니다.
- 한 앨범의 곡이라면 걸러진 목록에서 **이 표지를 목록 전체에** → **전체 저장**으로 표지만 한꺼번에 채울 수 있습니다.
- 명령줄에서는 `--only-missing-cover`로 같은 일을 합니다.

**Music Tag Filler v0.2.8** adds a box, **Add only files without a cover**. With it ticked, songs that already have a cover (album art) stay out of the list when you add files or a folder, subfolders included; a song with title and artist filled in is still listed if it has no cover. The status line starts with how many songs were skipped. The box sits under the cover buttons, or under Add files · Add folder · Clear once the file list shows; it is off at first and stays ticked the next time. For songs from one album, **Use this cover for all** and then **Save all** fill in just the covers. On the command line, use `--only-missing-cover`. Everything else is the same as v0.2.7. Download `music-tag-filler.exe` and double-click it. The exe is not signed, so if SmartScreen warns, choose "More info → Run anyway".

**音乐标签补全 v0.2.8** 新增选项**只添加无封面的文件**。勾选后添加文件或文件夹（含子文件夹）时，已有封面（专辑图片）的歌曲不会进入列表；即使标题、歌手都已填好，只要没有封面就会列出。状态栏开头会显示跳过了多少首。该选项在没有文件时位于封面按钮下方，出现文件列表后位于「添加文件 · 添加文件夹 · 清空」下方；默认不勾选，勾选后下次打开仍保持。同一张专辑的歌曲可接着点**将此封面用于全部**再点**全部保存**，只把封面一次补齐。命令行使用 `--only-missing-cover`。其他功能与 v0.2.7 相同。下载 `music-tag-filler.exe` 并双击运行。exe 未签名，若 SmartScreen 提示，请选择“更多信息 → 仍要运行”。

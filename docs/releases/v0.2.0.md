## 음악 정보 채우기 v0.2.0

가사를 채울 수 있게 된 버전입니다. 기본은 꺼져 있고, 켜지 않으면 v0.1.8과 똑같이 동작합니다.

### 새 기능: 가사도 채우기

아래 옵션 줄의 **가사도 채우기**를 켜면, 저장할 때 가사가 없는 파일에 [LRCLIB](https://lrclib.net/) 가사를 넣습니다. 옆의 **!** 버튼을 누르면 주의 사항이 나오고, 처음 켤 때도 한 번 나옵니다.

- 곡 제목·아티스트·길이만 보냅니다. 이미 있는 가사는 바꾸지 않습니다. 단, `[COWON S9]`처럼 플레이어 표시만 있는 가사 칸은 빈 칸으로 봅니다.
- 틀린 가사보다 빈 가사가 낫다는 원칙으로, 아티스트·버전(반주·TV 사이즈)·길이(3초 이내)가 맞고, 올라온 기록끼리 내용이 일치할 때만 넣습니다. 같은 글을 여러 번 올린 것은 한 건으로 세고, 내용이 갈리면 넣지 않습니다. 일본어 원문과 로마자 표기가 함께 있으면 원문을 씁니다.
- 반주(Instrumental·Off Vocal·Karaoke) 파일에는 넣지 않습니다. 시간 표시 없는 일반 가사만 넣습니다.
- 파일 정보 아래 **가사:** 줄에 결과가 나오고, **가사 보기**로 내용을 볼 수 있습니다.
- 서버가 바쁘면 잠깐 기다려 다시 묻고, 그래도 안 되면 태그만 저장합니다. 다시 저장하면 다시 찾습니다.
- **되돌리기**로 가사를 넣기 전 파일로 바이트 단위까지 돌아갑니다.
- 명령줄: `music-tag-filler.exe 폴더 --auto --lyrics`
- 가사에는 저작권이 있습니다. 개인 소장 파일에만 쓰세요.

실제 라이브러리 사본으로 잰 결과(2026-10):

| 라이브러리 | 가사를 찾은 비율 |
| --- | --- |
| J-POP 가수 앨범 위주 879곡 | 47% |
| 가수 앨범·애니·OST가 섞인 200곡 표본 | 29% |
| 80년대 J-POP 100곡 표본 | 25% |

이미 가사가 든 85곡과 대조하면 70곡을 찾았고, 그중 68곡은 같은 가사, 1곡은 같은 곡의 로마자 표기였습니다. 찾은 가사를 쓰고 되돌린 465곡은 모두 원본과 바이트 단위로 같았습니다.

### 고친 것

- 작업 스레드가 화면 값을 직접 읽던 부분을 고쳤습니다(검색 국가·검색어·옵션).
- 예상 못 한 저장 오류를 "읽기 전용"으로 알리던 것을 "저장하지 못했습니다(자세한 내용은 music-tag-filler.log)"로 구분합니다. 저장 직후 파일을 다시 읽지 못해도 작업이 멈추지 않습니다.
- 명령줄 `--auto`가 표지를 받으려 하지 않았는데도 "표지를 내려받지 못함"이라고 알리던 문제.
- 저장 중 취소하면 상태 줄에 "취소됨"이 남습니다.

백업 파일에는 원래 가사가 함께 기록됩니다. 이전 버전이 만든 백업으로도 그대로 되돌릴 수 있고(옛 백업 61개로 확인), [음악 폴더 정리](https://github.com/microhan1/music-folder-organizer)와의 연동도 그대로입니다.

**Music Tag Filler v0.2.0** — adds optional lyrics (off by default; with it off the app behaves like v0.1.8). Turn on **Also fill lyrics** and saving adds lyrics from [LRCLIB](https://lrclib.net/) to files that have none; the **!** button explains the cautions. Only the title, artist and length are sent. A missing lyric is preferred to a wrong one: lyrics are added only when artist, version (instrumental / TV size) and length match and the submitted records agree with each other (copies count once, a split means nothing is added, the original script beats a romanised copy). Instrumental files are skipped, only plain lyrics are written, existing lyrics are kept (a tag holding only a player marker such as `[COWON S9]` counts as empty), and Undo restores the file byte for byte. CLI: `--lyrics`. Measured on real libraries: 25–47% of songs found depending on the library; of 85 files that already had lyrics, 70 were found and 68 matched exactly. Also fixed: worker threads reading Tk variables, unexpected save errors reported as "read-only", a false "cover could not be downloaded" message in `--auto`, and "Cancelled" now stays on the status line. Old backups still restore.

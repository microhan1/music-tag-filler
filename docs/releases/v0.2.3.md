## 음악 정보 채우기 v0.2.3

새 버전 알림의 [업데이트] 버튼이 화면 언어에 맞는 페이지를 열도록 고친 버전입니다. 태그·가사·되돌리기는 v0.2.2와 같습니다.

### 바뀐 것

- **[업데이트]가 여는 페이지.** 화면 언어가 한국어면 지금처럼 한국어 툴 페이지를, 영어·일본어·중국어면 영어 판 툴 페이지(chaekgalpi.co.kr/en/tools/musictag)를 엽니다. 영어 판 주소는 책갈피 서버가 알려 줄 때만 쓰고, 알려 주지 않거나 책갈피 사이트 주소가 아니면 한국어 페이지를 엽니다.
- 서버로 보내는 정보(도구 이름·버전·OS 계열)와 확인 방식(하루 한 번, 끌 수 있음)은 그대로입니다.
- 영어 README의 책갈피 링크도 영어 판 페이지로 바꿨습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

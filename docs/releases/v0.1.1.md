## 음악 정보 채우기 v0.1.1

v0.1.0 이후의 속도·메모리·사용성 개선입니다. 사용법은 [v0.1.0 릴리스](https://github.com/microhan1/music-tag-filler/releases/tag/v0.1.0)와 README를 참고하세요.

### 바뀐 것

- **검색이 빨라졌습니다.** 파일당 4.7~7.6초(검색 국가 KR 기준)에서 0.3~2.1초로. 음원이 없는 KR 스토어를 건너뛰고 바로 US를 부르고, iTunes 제한을 "3.1초마다 1회"에서 "60초 창에 20회"로 바꿔 한 곡 검색은 즉시 나갑니다. iTunes와 MusicBrainz를 동시에 호출하고, 표 썸네일은 4개씩 병렬로 받습니다.
- **메모리를 적게 씁니다.** 300곡(표지 800KB씩) 로딩 시 +240MB → +2MB. 표지는 화면에 보일 때와 저장할 때만 파일에서 읽고, 내려받은 표지는 임시 파일에 둡니다. 하단 오른쪽에 현재 사용량(MB)을 표시합니다.
- **저장 후 알림 창을 옵션으로.** "저장 후 알림 창 표시" 체크박스(기본 꺼짐). 꺼져 있으면 상태줄에 저장 수와 백업 파일명을 보여 주고, 저장 실패가 있으면 옵션과 무관하게 오류 창을 띄웁니다.
- **파일 목록이 튀지 않습니다.** 파일을 클릭하거나 칸에 입력할 때 목록 스크롤과 선택이 흔들리던 문제를 고쳤습니다.
- exe도 명령줄 인자를 받는다는 점을 README에 적었습니다(콘솔 출력이 안 보이는 환경에서는 `> log.txt`로 보내거나 소스로 실행).

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

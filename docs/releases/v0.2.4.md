## 음악 정보 채우기 v0.2.4

창 위쪽에 **의견 보내기** 버튼을 더한 버전입니다. 태그·가사·되돌리기·새 버전 확인은 v0.2.3과 같습니다.

### 바뀐 것

- **의견 보내기.** 「새 버전 확인」 오른쪽 버튼을 누르면 책갈피 툴 페이지의 의견 칸(chaekgalpi.co.kr/tools/musictag#feedback)이 브라우저로 열리고, 거기서 로그인 없이 안 되는 것·불편한 것·바라는 기능을 보낼 수 있습니다. 화면 언어가 영어·일본어·중국어면 영어 판 페이지가 열립니다.
- 버튼은 페이지를 열기만 합니다. 프로그램이 서버로 보내는 것은 없고, 주소에는 프로그램에서 왔다는 표시와 버전만 붙습니다.
- 브라우저가 열리지 않으면 주소를 복사할 수 있는 작은 창이 뜹니다.
- 창이 가장 작을 때 위쪽 안내 글이 옆 칸에 붙지 않도록, 자리가 모자라면 "…"로 줄여 보여 줍니다.
- GitHub Issues도 그대로 받습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Tag Filler v0.2.4** — adds a **Send feedback** button at the top of the window, right of "Check for updates". It opens the feedback box on the Chaekgalpi tools page in your browser (the English page on English, Japanese and Chinese screens), where you can send a note without signing in. The button only opens the page: the app sends nothing itself, and the address carries only a "from the app" marker and the version. If no browser opens, a small window shows the address to copy. At the smallest window size the top hint now shortens with "…" instead of running into the next label. GitHub Issues are welcome as before. Tagging, lyrics, undo and the update check are the same as v0.2.3.

## 음악 정보 채우기 v0.2.1

새 버전이 나오면 알려 주는 기능을 더한 버전입니다. 태그·가사·되돌리기는 v0.2.0과 같습니다.

### 새 기능: 새 버전 확인

- 실행할 때 새 버전이 있는지 확인하려고 **도구 이름(`musictag`)과 버전만** 책갈피 서버(chaekgalpi.co.kr)에 보냅니다. 파일·경로·기기 정보는 보내지 않습니다.
- **하루 한 번만** 확인합니다. 창이 뜬 뒤 백그라운드에서 묻고, 연결이 안 되면 아무것도 표시하지 않습니다.
- 위쪽 언어 선택 옆의 **새 버전 확인**을 끄면 묻지 않습니다(기본은 켜짐).
- 새 버전이 있으면 창 아래에 "새 버전 x.y.z이 있습니다 (현재 0.2.1) · [업데이트] [다음에]" 한 줄이 나옵니다. **업데이트**는 책갈피 툴 페이지를 열고, **다음에**를 누르면 그 버전은 다시 알리지 않습니다. 자동으로 내려받거나 바꾸지 않습니다.

이 때문에 README의 "파일은 올라가지 않습니다 · 서버 없음" 문구에 "새 버전 확인만 예외(도구 이름·버전만, 하루 한 번, 설정에서 끔)"를 덧붙였습니다.

**Music Tag Filler v0.2.1** — adds an update check; tagging, lyrics and undo are the same as v0.2.0. At start-up the app sends only the tool name (`musictag`) and its version to the Chaekgalpi server (chaekgalpi.co.kr) to see whether a newer version exists — no files, paths or device information. It checks at most once a day, in the background, shows nothing when offline, and can be turned off with **Check for updates** next to the language selector. When a newer version exists a one-line notice appears at the bottom: **Update** opens the tool's page on the Chaekgalpi site, **Later** hides that version for good. Nothing is downloaded or replaced automatically. The README's "files are never uploaded / no server" lines now note this single exception.

## 음악 정보 채우기 v0.2.6

화면에 다 보이지 않던 것 두 가지를 고친 버전입니다. 태그·가사·되돌리기·새 버전 확인·의견 보내기는 v0.2.5와 같습니다.

### 바뀐 것

- **「이 표지를 목록 전체에」 버튼이 가려지던 것.** 파일을 두 개 이상 넣으면 이 버튼이 나타나는데, 위 칸(현재 파일 정보)이 버튼만큼 늘어나지 않아 가는 선으로만 보일 때가 있었습니다. 이제 버튼이 나타나면 위 칸이 그 높이에 맞춰 늘어납니다. 위·아래 칸 경계를 직접 옮겼다면 그 자리는 그대로 둡니다.
- **높은 화면 배율에서 창이 화면보다 크던 것.** 화면 배율 150%에서는 창이 1230픽셀 높이로 열려, 1920×1080 노트북 같은 화면에서는 아래쪽 「저장」 버튼 줄과 상태 줄이 작업 표시줄 아래로 숨었습니다. 이제 창은 작업 표시줄을 뺀 화면 안에 들어오는 크기로, 화면 가운데에 열립니다. 큰 화면에서는 예전과 같은 크기입니다.
  - 작은 화면(예: 1920×1080에 150%)에서는 위 칸과 저장 줄을 먼저 보이게 하므로 검색 결과 표가 거의 안 보일 수 있습니다. 위·아래 칸 사이 경계를 위로 끌면 표가 넓어집니다.

**Music Tag Filler v0.2.6** fixes two things that did not fit on screen. With two or more files, the "Use this cover for all" button could show as a thin line because the upper pane did not grow for it; the pane now grows when the button appears (a divider you moved yourself stays where you put it). At 150% display scale the window opened 1230 pixels tall, so on a 1920×1080 laptop the Save row and status line were hidden under the taskbar; the window now opens centred and small enough to fit the screen without the taskbar, and keeps its old size on large screens. On small screens the upper pane and the Save row come first, so the results table may show few or no rows; drag the divider up to make it larger. Tagging, lyrics, undo, the update check and Send feedback are the same as v0.2.5.

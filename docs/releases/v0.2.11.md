## 음악 정보 채우기 v0.2.11

표지를 받거나 읽는 동안 표지 칸에 「표지 불러오는 중…」이 나오게 한 버전입니다. 태그·가사·되돌리기·새 버전 확인·의견 보내기는 v0.2.10과 같습니다.

### 바뀐 것

- **표지를 받는 중이면 표지 칸에 「표지 불러오는 중…」이 나옵니다.** 전에는 받는 동안에도 표지가 없을 때와 같은 악보 그림(또는 그 곡의 예전 표지)이 보여서, 아직 받는 중인지 표지가 없는 건지 알 수 없었습니다. 후보를 두 번 눌러 적용하거나 「선택 적용」을 누른 때, 목록 검색이 후보를 자동으로 고른 때 모두 표지를 다 받을 때까지 이 글자가 보입니다. 다른 일이 끝나기를 기다리는 동안에도 마찬가지입니다.
- 받지 못하면 글자가 사라지고 원래 모양으로 돌아갑니다. 그 곡에 원래 표지가 있으면 그 표지, 없으면 악보 그림입니다. 「취소」를 누르거나 다른 후보, 표지 파일을 골라도 같습니다.
- 곡을 고를 때 파일 안 표지를 읽고 줄이는 일을 화면과 따로 해서, 큰 표지가 든 곡을 골라도 창이 멈추지 않습니다. 읽는 데 0.15초가 넘게 걸릴 때만 「표지 불러오는 중…」이 나오므로, 목록을 빨리 넘겨도 글자가 깜박이지 않습니다.

### 고친 것

- 표지를 받는 사이 다른 곡을 고르면, 늦게 도착한 앞 곡 표지가 지금 곡 자리에 잠깐 그려질 수 있었습니다. 이제 지금 보이는 곡의 표지만 그립니다.
- 표지를 받는 사이 「표지 파일 고르기…」로 고른 그림이, 늦게 도착한 후보 표지에 덮이지 않습니다.

**Music Tag Filler v0.2.11** shows "Loading cover…" in the cover box while a cover is being downloaded or read. Before, the box showed the same music-note picture as a song with no cover (or the song's old cover) during the download, so you could not tell whether the cover was still coming. The text now stays from the moment you apply a candidate (double-click or "Apply selected"), or the list search picks one for you, until the cover arrives, including while it waits for another job to finish. If no cover is found, the box goes back to the song's own cover or the note; the same happens after Cancel or when you pick another candidate or an image file. Reading and shrinking a file's own cover now runs apart from the window, so the window no longer stalls on a large cover, and the text appears only when that takes longer than 0.15 seconds. A cover that arrives late for a song you have already left is no longer drawn over the song on screen, and an image file you pick while a download is running is no longer replaced when the download ends. Everything else is the same as v0.2.10. Download `music-tag-filler.exe` and double-click it. The exe is not signed, so if SmartScreen warns, choose "More info → Run anyway".

**音乐标签补全 v0.2.11** 在下载或读取封面时，封面框中会显示“正在加载封面…”。以前下载期间显示的是与没有封面时相同的音符图（或该歌曲原来的封面），无法分辨是还在下载还是没有封面。现在从应用候选（双击或“应用所选”）或列表搜索自动选中候选开始，到封面下载完成为止都会显示这段文字，等待其他任务结束时也一样。找不到封面时，会恢复为歌曲原有的封面或音符图；点击“取消”、改选其他候选或选择图片文件时也是如此。读取并缩小文件内封面的工作改为与窗口分开进行，遇到大封面时窗口不再卡住，只有耗时超过 0.15 秒才显示文字。已经切换到其他歌曲后才下载完成的封面，不会再画到当前歌曲上；下载过程中选择的图片文件也不会在下载结束后被替换。其他功能与 v0.2.10 相同。下载 `music-tag-filler.exe` 并双击运行。exe 未签名，若 SmartScreen 提示，请选择“更多信息 → 仍要运行”。

**音楽タグ補完 v0.2.11** ジャケットの取得中・読み込み中に、ジャケット欄に「ジャケットを読み込み中…」と表示するようにしました。これまでは取得中もジャケットがないときと同じ音符の絵（またはその曲の元のジャケット）が出ていて、まだ取得中なのかジャケットがないのか区別できませんでした。候補を適用したとき（ダブルクリックまたは「選択を適用」）や一覧の検索が候補を自動で選んだときから、ジャケットが届くまでこの表示が出ます。ほかの処理の終了を待っている間も同じです。見つからなかった場合は、その曲の元のジャケットか音符の絵に戻ります。「キャンセル」を押したときや、別の候補・画像ファイルを選んだときも同じです。ファイル内のジャケットの読み込みと縮小を画面とは別に行うようにしたので、大きなジャケットでも画面が止まらず、0.15 秒を超えたときだけ表示が出ます。別の曲に移ったあとで届いた前の曲のジャケットが、今の曲の欄に描かれることはなくなりました。取得中に選んだ画像ファイルが、取得の完了後に置き換えられることもなくなりました。その他の機能は v0.2.10 と同じです。`music-tag-filler.exe` をダウンロードしてダブルクリックしてください。署名なしのため SmartScreen が警告する場合は「詳細情報 → 実行」を選んでください。

## 음악 정보 채우기 v0.1.5

### 바뀐 것

- **표지 일괄 등록.** 여러 파일을 넣으면 표지 미리보기 아래에 「이 표지를 목록 전체에」 버튼이 나타납니다. 표지가 있는 파일을 고르고 누르면, 확인 후 그 표지를 목록의 다른 파일 전부에 넣습니다. 앨범 폴더를 통째로 넣었을 때 한 번에 표지를 맞출 수 있습니다. 파일에는 「전체 저장」을 눌러야 기록되고, 되돌리기도 그대로 됩니다.

사용법은 README와 [v0.1.0 릴리스](https://github.com/microhan1/music-tag-filler/releases/tag/v0.1.0)를 참고하세요.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

## 음악 정보 채우기 v0.1.2

v0.1.1 이후의 두 가지 수정입니다. 사용법은 README와 [v0.1.0 릴리스](https://github.com/microhan1/music-tag-filler/releases/tag/v0.1.0)를 참고하세요.

### 바뀐 것

- **후보 표 썸네일이 대부분 비어 있던 문제를 고쳤습니다.** 표가 갱신되거나 파일을 오갈 때 진행 중이던 썸네일 요청을 버리고 처음부터 다시 시작해서, 23줄 중 2줄만 이미지가 붙는 일이 있었습니다. 이제 썸네일은 URL마다 한 번만 받아 캐시하고 표에 그 줄이 있으면 붙입니다. 빠른 iTunes 썸네일을 먼저, 느린 Cover Art Archive 것을 뒤에 받습니다.
- **파일명의 버전 표기를 제목의 일부로 봅니다.** `Time Pavement - Karaoke.flac`을 "가수 - 제목" 규칙으로 잘라 엉뚱한 곡을 찾던 문제입니다. Karaoke·off vocal·Instrumental·TV size·Remix·Live·Japanese Version 같은 말이 뒤에 붙으면 `Time Pavement (Karaoke)` 한 제목으로 검색하고, karaoke·off vocal·instrumental은 같은 말로 비교합니다. 아즈망가 대왕 캐릭터 CD의 FLAC 3곡으로 확인: 텍스트 검색 정답이 1/3에서 3/3이 됐습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Tag Filler v0.1.2** — Candidate thumbnails now load reliably (each URL is fetched once and cached instead of being abandoned whenever the table refreshes), and a trailing version word in a file name (`- Karaoke`, `- off vocal`, `- TV size`, `- Remix`, ...) is treated as part of the title rather than as the artist/title separator, with karaoke, off vocal and instrumental compared as the same word.

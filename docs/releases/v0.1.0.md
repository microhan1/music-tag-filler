## 음악 정보 채우기 v0.1.0

정보(제목·가수·앨범·표지)가 비어 있는 mp3·flac·m4a·ogg를 끌어다 놓으면, 파일에 든 정보를 위쪽에, iTunes·MusicBrainz·AcoustID에서 찾은 후보를 아래쪽에 보여 주고, 고른 후보를 파일에 써 넣는 Windows 단일 실행 파일입니다.

**파일은 인터넷으로 올라가지 않습니다.** 검색어와 음향 지문(숫자 열)만 보냅니다.

### 사용법

1. `music-tag-filler.exe`를 받아 더블클릭합니다. 설치 없음. (서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행")
2. 음악 파일이나 폴더를 창에 끌어다 놓습니다. 파일명·기존 태그로 검색이 바로 돌아갑니다.
3. 후보를 고르고 **선택 적용** → **저장**. 원래 태그는 `<파일명>.tagbak.json`에 남고, **되돌리기**로 바이트 단위까지 복구됩니다.

- 여러 파일을 넣으면 일치도 90 이상인 첫 후보를 자동 선택해 두고(빈 칸만 채움), 확인 후 **전체 저장**을 누르면 됩니다.
- 제목·가수가 전혀 없는 `track01.mp3` 같은 파일은 **소리로 찾기**를 누르세요. fpcalc(Chromaprint)와 AcoustID 키가 exe에 들어 있어 별도 설정이 필요 없습니다.
- 한국어·English·中文·日本語 UI. 언어와 검색 국가는 우상단에서 바꿉니다.

### 이 버전에 들어 있는 것

- iTunes Search API + MusicBrainz 텍스트 검색, AcoustID 음향 지문 검색, Cover Art Archive·iTunes 표지
- 표지는 JPEG, 긴 변 1000px 이하로 넣습니다. mp3는 ID3v2.3, flac은 PICTURE, m4a는 covr, ogg는 METADATA_BLOCK_PICTURE
- 인터넷이 없어도 편집·저장·되돌리기는 됩니다
- 명령줄: `music-tag-filler.exe song.mp3 [--auto] [--country KR] [--rename] [--sound] [--undo]`. 창 모드 exe라 콘솔에 출력이 안 보이는 환경이 있으니, 그럴 때는 `> log.txt`로 보내거나 소스에서 `python main.py`로 쓰세요

**Music Tag Filler v0.1.0** — Drop untagged mp3 / flac / m4a / ogg, pick a match from iTunes / MusicBrainz / AcoustID, save title, artist, album and cover art. Files are never uploaded; only the query and an audio fingerprint are sent. The exe bundles fpcalc (Chromaprint, LGPL-2.1) and an AcoustID application key, so "Find by sound" works out of the box. Unsigned exe: if SmartScreen warns, choose "More info → Run anyway". UI in Korean, English, Chinese and Japanese.

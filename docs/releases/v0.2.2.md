## 음악 정보 채우기 v0.2.2

v0.2.1에서 더한 「새 버전 확인」을 더 안전하게 고친 버전입니다. 태그·가사·되돌리기는 v0.2.1과 같습니다.

### 고친 것

- **새 버전 확인 중에 창을 닫으면 프로그램이 비정상 종료될 수 있던 구조.** 창이 뜬 뒤 서버 답을 기다리는 몇 초 사이에 창을 닫으면, 확인하던 작업 스레드가 화면 객체를 붙잡고 있다가 엉뚱한 스레드에서 정리해 프로그램이 죽을 수 있었습니다(같은 방식으로 만든 다른 도구에서 실제로 발생). 이제 작업 스레드는 결과만 담고 화면은 전혀 건드리지 않습니다. 빌드한 exe로 확인 직후에 창을 닫아 보는 시험을 여러 번 해 모두 정상 종료했습니다.
- 한국어 알림 문구를 "새 버전이 나왔습니다: x.y.z (현재 0.2.2)"로 바꿨습니다(전에는 버전 뒤 조사가 어색했음).
- README 화면 그림을 지금 화면(가사 옵션·새 버전 확인 포함)으로 바꿨습니다.

새 버전 확인의 동작(하루 한 번, 도구 이름·버전만, 끌 수 있음)과 보내는 정보는 v0.2.1과 같습니다.

**Music Tag Filler v0.2.2** — makes the v0.2.1 update check safe to interrupt; tagging, lyrics and undo are unchanged. Closing the window during the few seconds the check waits for the server could end the program abnormally (the worker thread held on to window objects and released them on the wrong thread; it happened in a sibling tool built the same way). The worker now only stores its result and never touches the window; the built exe was closed right after the check started several times and always exited cleanly. The Korean notice text was reworded, and the README screenshot now shows the current window. What the update check sends and how often are the same as v0.2.1.

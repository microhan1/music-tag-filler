## 음악 정보 채우기 v0.2.10

여러 곡을 검색하는 동안 고른 후보의 표지가 바뀌지 않던 문제를 고친 버전입니다. 태그·가사·되돌리기·새 버전 확인·의견 보내기는 v0.2.9와 같습니다.

### 고친 것

- **목록 검색 중에 후보를 골라도 표지가 함께 바뀝니다.** 여러 곡을 넣어 「검색 중 24/31」처럼 검색이 도는 동안, 검색이 끝난 곡에서 후보를 두 번 눌러 적용하면 제목·앨범·발매년도는 바뀌고 표지만 그대로였습니다. 그대로 저장하면 예전 표지가 남았습니다. 이제 표지는 다음 곡으로 넘어가기 전에 받아 바로 보입니다. 한 곡에서 후보를 여러 번 바꾸면 마지막에 고른 후보의 표지만 받고, 「취소」를 누르면 기다리던 표지도 받지 않습니다(고른 태그는 남습니다).
- **검색 중에 검색어 칸에서 Enter를 눌러도 후보 표가 비지 않습니다.** 전에는 검색 단추가 회색인데도 Enter가 들어가 표만 비고 검색은 되지 않았습니다. 이제 검색이 끝날 때까지 아무 일도 하지 않습니다.

**Music Tag Filler v0.2.10** fixes covers picked while a list is still being searched. With several songs added and the search running ("Searching 24/31"), double-clicking a candidate for a song that was already searched changed the title, album and year but left the old cover, and saving kept it. The cover is now fetched before the search moves on to the next song and shows at once. If you change your pick for a song several times, only the last pick's cover is fetched; Cancel drops the waiting covers and keeps the tags you picked. Pressing Enter in the search box during the search no longer empties the candidate table. Everything else is the same as v0.2.9. Download `music-tag-filler.exe` and double-click it. The exe is not signed, so if SmartScreen warns, choose "More info → Run anyway".

**音楽タグ補完 v0.2.10** 一覧を検索している間に選んだ候補のジャケットが変わらない問題を直しました。複数の曲を入れて検索中（「検索中 24/31」など）に、検索済みの曲で候補をダブルクリックすると、タイトル・アルバム・年は変わるのにジャケットだけ古いままで、保存しても古いジャケットが残っていました。今はジャケットを次の曲の検索に移る前に取得し、すぐに表示します。同じ曲で候補を何度も変えた場合は最後に選んだ候補のジャケットだけを取得し、「キャンセル」を押すと待っていたジャケットは取得しません（選んだタグは残ります）。検索中に検索欄で Enter を押しても候補表が空になることはなくなりました。その他の機能は v0.2.9 と同じです。`music-tag-filler.exe` をダウンロードしてダブルクリックしてください。署名なしのため SmartScreen が警告する場合は「詳細情報 → 実行」を選んでください。

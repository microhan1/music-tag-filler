## 음악 정보 채우기 v0.1.7

### 바뀐 것

- **README에 [음악 폴더 정리](https://github.com/microhan1/music-folder-organizer) 안내를 넣었습니다.** 태그를 채운 다음 `가수/앨범/01 - 제목.mp3` 구조로 옮기고 중복을 정리하는 짝 도구입니다.
  - 여기서 적는 MusicBrainz·iTunes 아티스트 ID로 `岡田 有希子`·`岡田有希子`·`Yukiko Okada` 같은 표기 차이를 한 폴더로 묶습니다(음악 폴더 정리 v0.1.2 이상).
  - 이 도구의 백업 `<파일명>.tagbak.json`이 음악 파일과 함께 옮겨지므로, 폴더를 정리한 뒤에도 여기서 **되돌리기**가 됩니다.
- **서버에 보내는 앱 버전을 바로잡았습니다.** MusicBrainz·iTunes·AcoustID에 요청할 때 보내는 이름표(User-Agent)가 그동안 `0.1.0`으로 나가고 있었습니다. 이제 실제 버전(`0.1.7`)을 보냅니다. MusicBrainz 이용 규칙이 정확한 앱 이름과 버전을 요구합니다.

검색·저장·되돌리기 기능과 태그 형식은 v0.1.6과 같습니다.

### 다운로드

`music-tag-filler.exe`를 받아 더블클릭합니다. fpcalc(Chromaprint, LGPL-2.1)와 AcoustID 키가 들어 있어 별도 설정 없이 소리로 찾기까지 됩니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".
